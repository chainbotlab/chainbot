# AGENTS.md

## Scope
- Position: AI-generated task specification bucket.
- Owns: Executable task specs derived from PRDs, decision summaries, or resolved conversation context.
- Excludes: Final stable decisions, exploratory research, implementation records, and incident postmortems.

## Constraints
- Name files `{YYYY_MM_dd}_{task_name}.md`.
- Keep specs actionable and implementation-ready.
- Move superseded specs to `docs/archive/` instead of leaving them in the active task-spec bucket.

## Members
- AI-generated task specification docs.
