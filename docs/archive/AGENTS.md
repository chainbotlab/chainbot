# AGENTS.md

## Scope
- Position: Retired docs and tombstones bucket.
- Owns: Superseded plans, proposals, and implementation history retained for context.
- Excludes: Active working-set docs and current design decisions.

## Constraints
- Archive durable material instead of deleting it when it still explains prior decisions.
- Move obsolete or superseded material here rather than leaving it in active buckets.

## Members
- `decisions/`: Archived decision snapshots and tombstones.
- Official-plugin rollout plans and SDK migration records retained as historical context.
